Các Công Việc Đã Thực Hiện

Giai đoạn 1–2: Nền tảng

  • Xây dựng kiến trúc 6 lớp phân tầng rõ ràng
  • Driver UART bit-banging 9600bps trên PC0/PC1
  • Driver 8255: điều khiển WR#/RD#/CS# theo timing diagram
  • Device Service: bitmask uint8_t quản lý 8 thiết bị

Giai đoạn 3–6: Nâng cao

  • Memory Map 16-bit: ROM 0x0000, RAM 0x4000, IO 0x8000
  • CPU Bus Layer: cpu_bus_read/write(addr)
  • ADC0804 qua 8255 Port B/C + MUX 74HC4051 8 kênh
  • Protocol Frame: [AA][CMD][LEN][DATA][CHECKSUM]
  • Push định kỳ CMD_SENSOR_DATA (9 byte payload)

Phần cứng: Schematic & PCB

  • Sơ đồ nguyên lý Proteus đầy đủ 33 linh kiện
  • BOM chi tiết: IC DIP, relay, MUX, ADC, nguồn
  • Sơ đồ nối dây (Wire List): Data bus, control bus, MUX
  • Lưu ý thiết kế PCB: star ground, relay isolation, bypass

Kết Quả Đã Đạt Được

Kết quả kỹ thuật

  • ✅ Bật/tắt chính xác 8 Relay qua 8255 Port A, phản hồi ACK
  • ✅ Đo dòng 8 kênh: MUX 74HC4051 → ADC0804 → Port B
  • ✅ Frame XOR checksum hoạt động ổn định, lọc nhiễu UART
  • ✅ Push tự động CMD_SENSOR_DATA mỗi ~500ms (9 byte)
  • ✅ Memory map đúng bản chất vi xử lý: ROM/RAM/IO phân vùng
  • ✅ Logic phát hiện lỗi: ON+không dòng = LỖI; OFF+có dòng = CẢNH BÁO
  • ✅ Sơ đồ nguyên lý Proteus hoàn chỉnh (33 linh kiện)
  • ✅ PCB layout 2 lớp + Gerber file

Tiêu chuẩn đạt được

  • F_CPU = 8 MHz, UART 9600bps
  • 8255 Control Word = 0x82
  • Kiến trúc: 0 Spaghetti Code
  • Code dễ port sang MCU khác
  • PCB: Star grounding, relay isolation
  • BOM: 33 linh kiện DIP / through-hole

Kiến Trúc Phần Mềm 6 Lớp

Phân tầng (Top → Bottom)

main.c
└── app/ (điều phối)
├── protocol/ (frame, command)
├── services/ (device, measurement)
└── core/ (memory, cpu_bus, io_map)
└── drivers/ (uart, 8255, adc0804)
└── bsp/ + config/

Nguyên tắc thiết kế

  • Mỗi lớp chỉ gọi lớp ngay bên dưới
  • Tách biệt hoàn toàn logic và phần cứng
  • cpu_bus_write(0x8000, val) → 8255 Port A
  • Thay MCU chỉ cần sửa BSP layer
  • Zero Spaghetti Code

Giao Thức UART Frame

Cấu trúc Frame

AA │ CMD │ LEN │ DATA... │ XOR

Header │ Command │ Length │ Payload │ Checksum

Bộ lệnh

CMDTênMô tả
0x01SET_ALLĐặt 8 thiết bị
0x02SET_SINGLEBật/tắt 1 thiết bị
0x04SENSOR_DATAPush 9 byte dòng điện
0x81ACKPhản hồi OK
0x82NACKPhản hồi lỗi
